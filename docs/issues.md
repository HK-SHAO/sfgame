# 用户体验问题清单

老大（即用户）会定期把问题新增在此文档中。

针对每一个问题，研发人员（或 AI Agent 等）在阅读后需要着手核实、尝试复现、深度研究和思考。

注意老大的问题或建议不一定完全属实、合适或是最佳决策，要以第一性原理、产品体验和工程可靠且优雅为要义，批判性的研究、执行和回复。

每一个问题的状态要及时更新，例如是否已阅读，是否在执行中，执行结果或简要报告要体现。报告一定要挑重点，省略低信息量（即业界高频出现的模式）的细节，不能省略 bug 的修复或缺陷的改进。

老大负责最终给每个问题结束工单（用【ok】表示，只有老大才能结束工单，研发人员/Agent 没有权限），在此前研发绝不能忽视。

此文件仅供老大更改。如需汇报状态编辑 docs/issues 目录，文件名为 #N.md，参考业界的 issue 相关经验进行编辑。

## 2026/08/04

- #3 UI、画布和游戏内容更好的适配竖屏，例如手机。保持横屏的体验
- #4 风的粒子、纸飞机等移动物体增加拖尾特效，拖尾效果不要显眼，而是“淡淡的”，路程更长的拖尾轨迹会渐渐消失（非单纯随时间消失，而是随着路程的增加旧的轨迹淡出）。对于空气或风，我希望营造出真实的风的线条感（例如场的可视化）。对于可移动物体，我希望拖尾轨迹能够让用户直观感受到运动的历史（由于按照路程淡出轨迹，所以如果物体停止运动，对应可视的轨迹不会消失）。
- #5 第一关，纸飞机初始状态是在画布外且距离地面有一定高度，有一个合适的初速度表达出其速度感，如果不进行任何操作，飞机会很快落地而无法抵达目标。我的目标是这样能给玩家在一开始就构建出物理感、空气与纸飞机运动的真实感。
- #6 运动的物体，在空气中运动，会产生摩擦，会发出真实感的声音。用物理的方法和数学算法去产生游戏音效
