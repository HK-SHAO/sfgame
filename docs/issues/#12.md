# #12 HUD 紧凑常显 + 旗杆绿色残段 + 粒子轨迹丝滑 + 过关按钮居中

- **状态**：已实现、自测通过（`bun run check` 全绿 119 项）；观感待老大实玩验收
- **日期**：2026-08-05

## 1. HUD title 紧凑、常显，空间不足时横向滚动

- **删掉"窄屏隐藏 title"的媒体查询**：title 不再因屏宽隐藏（消除隐藏后按钮群间距不一致的观感），竖屏手机也常显
- **紧凑**：内边距 0.875rem→0.625rem、按钮间距 0.625rem→0.5rem；子项全部 `flex:none` 不压缩
- **溢出兜底 = 横向滚动**：`overflow-x:auto`；`syncHudOverflow()`（resize 监听 + 渲染后复查）检测 `scrollWidth > clientWidth` 时加 `.scroll` 类——显示细滚动条并接管该条带指针事件（否则 touch/wheel 滚动会被下方 canvas 吃掉）；无溢出时条带保持 `pointer-events:none`，顶部仍可透传到画布放源
- **宽屏观感不变**：title 用 `margin-inline:auto` 在左右两组按钮之间居中（溢出时 margin 塌缩为 0）
- 实测（headless Chrome 数值探针）：320px 竖屏下 title 常显（宽 92px）、溢出 449>320 正确启用滚动；1280px 桌面无溢出、title 居中

## 2. 抵达后旗杆不再残留绿色段

- 根因：旗杆绿色附着段（杆顶下 1.8 内的同色描边）烘焙进静态背景，抵达后旗面消失而绿色段仍留杆上
- 修法：绿色描边整体删除——旗面三角形左缘本就钉在杆线（flagTop→flagTop+1.8），飞行时该段由旗面覆盖、无需单独描边；全杆改为单一棕杆，抵达后只留棕杆
- 实测：旗帜飞行时杆顶条带 232 个目标绿像素（旗面覆盖）→ 置为已抵达后 **0**（含全屏）

## 3. 粒子轨迹丝滑 + 末尾圆润

- 根因：轨迹按每段平头四边形描边（`stroke`），转角露 V 形缺口、折线感强；末端平头截断
- 修法（`core/batch.ts` 新增 `polylineFade` + `ui/render.ts` 改写 `drawTracers`）：
  - 每条轨迹改画**一条斜接折线**（转角沿角平分线延伸、无缝相连），顶点数不变
  - **逐顶点透明度**：时间淡出直接写进顶点 alpha，段内线性渐变——淡出同样丝滑（旧实现按段定 alpha，段与段之间会跳变）
  - **头部圆帽**：粒子当前位置补半圆帽（8 段小圆盘，仅 24 顶点/粒子），轨迹末端不再平头截断
  - 180° 折返退化已有平头兜底，不回刺（沿用 `polyline` 的 miter 钳制）
- 实测：320px 档位 31k 顶点/帧（圆帽仅 +6%），batch 全帧零 NaN、alpha 范围 [0.003, 1]（渐变连续）；新增单测验证 `polylineFade` 逐顶点 alpha 与 `polyline` 几何一致

## 4. 过关弹窗「下一关」按钮居中

- 原三按钮并排居中，「下一关」只是组内靠左成员；改为**主按钮独占一行居中**（`flex:1` 拉伸至 15rem 封顶，卡片主 CTA 观感），「再玩一次」「选关」次按钮归第二行
- 最后一关时主行显示「再玩一次」
- 实测（320px）：下一关按钮中心 160px = 弹窗卡片中心 160px

## 修订（老大反馈 2026-08-05：HUD title 下沉到画面底部）

1. **header 移除关卡名**：横向空间吃紧，title 不再放在顶部 HUD；header 只留「主页/返回 + 源计数/速率/重置/声音」
2. **关卡名下移为底部 footer**：并入底部常驻状态卡（`status-bar.ts`，本就在画面最底、与 header 同款药丸设计语言）——第一行「第 N 关 名称 + 用时/罚时」，第二行操作说明。单独再放一个 footer 胶囊会与状态卡重叠，合并为一张底部卡是最干净的一致性解
3. header 溢出横向滚动兜底保留（320px 下仍会溢出）
- 实测：320px 竖屏底部卡居中贴底（center=160、距底 12.9px），header 无 title、溢出滚动正常
