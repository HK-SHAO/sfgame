## 实现（克制化，纯视觉）

新模块 `src/sim/clouds.ts`（无头、可测，与 Tracers 同款数组式结构；未来做云的玩法可整体升级为实体）：

- **物理性格（从简，第一性原理）**：一阶低通跟随风场——水平响应快（1.2/s）、垂直响应慢（0.25/s），云天然"难下降"；弱回复力（0.06/s）拉回出生高度 → 维持一定高度
- **淡出消失**：云底低到离地 3 单位（低于地形阈值，先淡没不会贴进山里）或漂出地图 30 单位（含高出顶界）→ 约 2 秒淡出 → 重生
- **可预测（伪随机）**：mulberry32，种子 = level id 的黄金比例哈希 → 同一关重开天上还是那几朵；相邻 id 布局也互不相同
- **出生域**：70% 空中、30% 地图外（边界外 8~20 单位漂入）；高度 = 该处地形高度的 15%~40% → 天空上三分之一、靠近顶部（实测各关 y≈3~17，世界高 56）
- **体积**：半径 5.6~9.6（最大体积 ≈ 太阳 14 倍，限制在 8~15 倍区间内；初版 4-10 倍→范围再翻→封顶）
- **数量**：3 朵（初版 6 朵减半；体积大、间距开）
- **累积下降消散**：每朵云一生累积下沉距离（dy>0 的累计）达 16 单位即提前淡出——被下沉风反复压低的云比贴地更早消散（贴地 FADE_ALT=3 规则保留兜底）
- **遮挡顺序**：动态层自底向上 = 云 → 地形 → 太阳 → 站点/源/示踪/飞机：云被山脊、太阳、飞机遮挡；为此**地形从烘焙背景移入动态层**（每帧重建，代价 ~2k 顶点，原烘焙仅因性能上移，逻辑无耦合）
- **渲染**：五团"实核+软边"径向渐变圆盘（`batch.discGradCore`，solidFrac=0.75：半径内 3/4 为实色、外 1/4 按 **smoothstep 曲线**衰减到透明——导数两头为 0，无线性渐变的棱带；模糊半径 = 1/4 云径）；淡出时实核同步收缩（α→0 时退化为纯渐变化散）→ 云由内而外丝滑消散；左右翼外移 1.7× 拉出宽扁云；近纯白（255,255,254），单盘 α 1.0/0.9/0.9/0.78/0.6 → 云核实白、边缘渐变保留雾状感；每云 ~1.6k 顶点、3 云 ~4.8k，零额外 draw call

## 参数审计（回应"云模拟渲染参数量是否过多"）

结论：**不算过多，未删减**。sim 层 16 个常量逐个对应本次工单的明确需求——难下降（RESPOND_V）、维持高度（HOME_RESTORE）、累积下沉消散（DESCEND_LIMIT）、贴地淡出（FADE_ALT）、出界消失（DESPAWN_MARGIN）、伪随机出生域（ALT_*/SPAWN_BAND_*/IN_AIR_RATIO）、淡入淡出（ALPHA_RATE/ALPHA_DEAD）、数量/体积（COUNT/R_*）；MIN+SPAN 成对写法与 `particles.ts` 同风格。render 侧 3 个常量 + 五盘偏移/半径/α 是"云的形状"本身（美术预算）。真正动刀处是把线性渐变升级为 smoothstep 软边（同样语义、更少视觉伪影）并移除其内部临时的线性棱带。

## 追加：关卡加载鲁棒性（r=0 白屏修复）

**症状**：goal 半径设为 0 时 `Uncaught Error: 关卡校验失败…` 直接白屏。

**根因**：`levels.ts` 模块顶层 `LEVEL_TEXTS.map(parseLevelText)`——任一条解析抛错，整个 bundle 求值失败，错误 UI 无从渲染。

**修法**（`game/levels.ts` + `ui/app.ts`）：
1. 逐关 try/catch 容错加载：坏关卡只进 `LEVEL_ERRORS` 清单（含错误原文），模块永不抛
2. 标题页渲染告警卡（`role="alert"` 红底小卡列出全部错误）；坏关卡从列表消失
3. 依赖首关的字段初始化（hud 预算初值）改 `?.` + `?? 0` 兜底；`startGame` 找不到关卡直接 return
4. 验证：临时把 level-1 的 r 改 0 → 标题页正常渲染、第 1 关消失、告警卡显示 "(id=1) goals[0] 需满足 0≤x≤w、0<r≤15"，console 无未捕获错误；已还原文件

**测试**：新增 r=0 被拒用例 + 「LEVEL_ERRORS 为空」守护用例；`bun run check` 全绿。
**pitfalls 回写**：D11（模块级初始化抛错 → 整包白屏）+ 快速检索行。
