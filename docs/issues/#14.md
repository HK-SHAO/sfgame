## 实现（克制化，纯视觉）

新模块 `src/sim/clouds.ts`（无头、可测，与 Tracers 同款数组式结构；未来做云的玩法可整体升级为实体）：

- **物理性格（从简，第一性原理）**：一阶低通跟随风场——水平响应快（1.2/s）、垂直响应慢（0.25/s），云天然"难下降"；弱回复力（0.06/s）拉回出生高度 → 维持一定高度
- **淡出消失**：云底低到离地 3 单位（低于地形阈值，先淡没不会贴进山里）或漂出地图 30 单位（含高出顶界）→ 约 2 秒淡出 → 重生
- **可预测（伪随机）**：mulberry32，种子 = level id 的黄金比例哈希 → 同一关重开天上还是那几朵；相邻 id 布局也互不相同
- **出生域**：70% 空中、30% 地图外（边界外 8~20 单位漂入）；高度 = 该处地形高度的 15%~40% → 天空上三分之一、靠近顶部（实测各关 y≈3~17，世界高 56）
- **体积**：半径 5.6~9.6（最大体积 ≈ 太阳 14 倍，限制在 8~15 倍区间内；初版 4-10 倍→范围再翻→封顶）
- **数量**：3 朵（初版 6 朵减半；体积大、间距开）
- **累积下降消散**：每朵云一生累积下沉距离（dy>0 的累计）达 16 单位即提前淡出——被下沉风反复压低的云比贴地更早消散（贴地 FADE_ALT=3 规则保留兜底）
- **遮挡顺序**：动态层自底向上 = 云 → 地形 → 太阳 → 站点/源/示踪/飞机：云被山脊、太阳、飞机遮挡；为此**地形从烘焙背景移入动态层**（每帧重建，代价 ~2k 顶点，原烘焙仅因性能上移，逻辑无耦合）
- **渲染**：五团"实核+软边"径向渐变圆盘（`batch.discGradCore`，solidFrac=0.75：半径内 3/4 为实色、外 1/4 线性衰减到透明——模糊半径 = 1/4 云径，较初版再减半）拼出蓬松剪影，无生硬接缝；左右翼外移 1.7× 拉出宽扁云；近纯白（255,255,254），单盘 α 1.0/0.9/0.9/0.78/0.6（初版 3 倍提不透明）→ 云核实白、边缘渐变保留雾状感；每云 ~1.1k 顶点、3 云 ~3.3k，零额外 draw call

## 接线

- `ui/controller.ts`：构造（`level.id` 作种子）+ `!frozen` 时随 sim 步进 → 暂停/过关冻结时云同冻结
- `ui/render.ts`：`SceneState.clouds` + `drawClouds`，绘制顺序在太阳之后、目标/飞机之前
- 不参与关卡判定，不碰流体场（只读采样），无任何玩法/回归影响
