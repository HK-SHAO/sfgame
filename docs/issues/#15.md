# #15 perf 面板升级为 dev 面板（关卡 YAML 临时编辑器）

- **状态**：已实现、`bun run check` 全绿（143 项测试）、headless Chrome 全流程实测通过
- **日期**：2026-08-05（同日修订三轮）

## 实现（最终版）

### 架构（perf 与关卡编辑完全解耦）

- `game/session.ts`（无头可测）：**单一开发槽 lv=0**——基础 YAML = 第 1 关；`setDevOverride`（解析+校验，失败抛错）、`getDevOverrideText`、`resolveLevel`（lv=0 取覆写否则第 1 关）。模块级内存，刷新即失、绝不落盘
- `game/state.ts`：`lv` codec 下限 1 → 0（编辑槽可达）
- **两个独立组件**（DevTools 只做组装，互不感知）：
  - `ui/perf.ts`（`sf-perf`）：等宽字体性能行 + 拖拽手柄（吸附四周）+ `<slot>` 装配点——只关心性能与定位，不知道编辑器的存在
  - `ui/level-editor.ts`（`sf-level-editor`）：关卡 YAML 编辑器（默认折叠、整行展开控件、`name="dev-level-yaml"`、非法文本内联报错）——只关心编辑，不关心定位/性能
- `ui/devtools.ts`：`perf.appendChild(editor)` 装配（随面板拖动）+ 转发 perf 样本 + 空格暂停
- `ui/app.ts`：`keyed(this.activeLevel)` 按关卡对象身份重建；监听事件 → 切 `?lv=0` 并清 `src`；`willUpdate` 对 activeLevel 变化重置 HUD

### 生效/复原语义

- 「确认生效」→ 会话覆写 + 跳转 **?lv=0**（默认内容即第 1 关）+ 清理 `src` → 游戏重建
- **无恢复按钮**：浏览器返回 → lv=1 原关卡（覆写在 lv=0 槽，永不污染内置关卡）
- 刷新页面 = 覆写丢失（会话级设计），lv=0 回落第 1 关默认内容

### 性能（两处根因修复）

1. **展开/收起"明显延迟"的真根因**：`expanded`/`editorText`/`error` 是普通字段没加 `@state()`——赋值不触发 Lit 重渲染，旧版靠每 1.5s 的 perf 刷新"顺带"重绘（实测点击后延迟 ≈ 一个刷新窗口）；修复后展开 0.9ms
2. **高速率长任务堵 UI**：8×/16× 下单帧 tick 批处理占满主线程，点击要等帧结束（实测 8× 下 63ms）。`core/loop.ts` 改为每批最多 6 tick、`setTimeout(0)` 让出主线程续跑（tick 顺序与 dt 不变，模拟确定性不受影响）；16× 下展开延迟 63ms+ → 15.8ms

## 验证（headless Chrome 实测）

1. perf 行等宽字体、拖拽手柄 `grab` 光标；编辑器整行展开控件、`name="dev-level-yaml"`（devtools 表单字段警告消失）✓
2. 拖拽隔离：手柄拖动面板移动；textarea/按钮按下不拖（composedPath 修复）✓
3. 展开 0.9ms（1×）/ 15.8ms（16×）✓
4. 编辑确认 → `?lv=0&dev=1`（src 清除）→ 游戏重建 ✓；浏览器返回 → lv=1 原关卡 ✓；重开编辑器预填覆写文本（继续迭代）✓
5. 非法 YAML 内联报错、游戏继续 ✓
