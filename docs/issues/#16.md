# #16 开发面板确认生效后不折叠 + 暂停按钮移到速率旁

- **状态**：已实现，`bun run check` 全绿
- **日期**：2026-08-06

## 根因

「确认生效」→ `onDevOverride` 换新关卡对象 → `keyed(activeLevel)` 重建 `sf-game` → `GameController` 销毁重建。面板（DevTools）当时由 **controller 持有**，随之销毁重建——新面板自然回到默认折叠态。#15 八修的「确认后保持展开」只修了编辑器组件自身不收起，没挡住面板整体被重建。

## 修复

- **面板生命周期上提到 `sf-app`**（`syncDevTools()` 于 `willUpdate` 执行）：游戏屏且 `?dev=1` 时创建，离开游戏屏/卸载时销毁。`sf-game` 以属性注入、`GameController` 只消费不创建/销毁。确认生效重建 `sf-game` 时面板实例不变——**展开状态、编辑器文本、拖拽位置全部延续**，可连续迭代；app 与游戏状态各司其职（游戏按新 YAML 重开，面板不丢上下文）
- **暂停按钮**：HUD 左组移到右组、紧邻速率按钮（主页 → ｜ 热源 冷源 暂停 速率 重置 声音）

## 验证

- typecheck/test/build 全绿（36 项测试）
- 面板属 dev 工具，按验证策略交由开发者实操验收（连续编辑 YAML → 确认生效 → 面板保持展开与文本）
