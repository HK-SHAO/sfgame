## 关键取舍

1. **物理内核是真流体，而非预设力场**：欧拉网格稳定流体（Stam）——温度场 → 浮力 → 压强投影，水平风由「温差 → 压强差」自然涌现，与 idea.md 的物理叙事一致；纸飞机与示踪粒子以拉格朗日方式**单向**耦合（风推物、物不扰风），这是游戏感受可接受范围内最大的简化。
2. **零新增运行时依赖**：未引 PixiJS / Matter.js。极简矢量风 Canvas 2D 足够；纸飞机用「质点 + 向风速收敛」比刚体引擎更简、更可控。
3. **模拟层无头可测**：`LevelSimulation` 不依赖 DOM，「关卡可通关」被写成回归测试（模拟玩家 bot：托举→爬升→滑翔进场，约 21s 通关），调参反馈环不靠浏览器。

## 第 1 关调参洞见（实际踩出的坑）

1. **悬停阈值**：飞机抬升条件是上升气流 > `gravity/dragK`。初版参数下贴地上升气流恰等于阈值，「能悬停但爬不动」；减轻飞机、增强浮力后才有裕度。
2. **几何死锁**：飞机停在地面时，热源无法放在「飞机下方」。解法：允许贴地放置，且落点在地面/物体上时**吸附到贴地高度**——「在飞机下方轻点」是核心交互，绝不能拒绝。
3. **水平运输**：升空后「向右飞」若全靠对流，体验混乱；改为第 1 关给一缕向右环境谷风（`ambient`），托住即护送，教学焦点保持在上升气流。少即是多。
