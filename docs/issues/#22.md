# #22 取景贴合世界 + 场景物体遮挡气流粒子

- **状态**：已完成，`bun run check` 全绿 + headless 数值化探针验证
- **日期**：2026-08-06

## 问题核实

两个症状同根于"画布铺满宿主、世界 contain 后界外继续画假天空"：

1. **左侧留白无气流、点击无效**：`fit` 把整个宿主尺寸交给渲染器，世界按 contain 缩放后左右（或上下）的界外区域仍被 `drawSky`/`drawTerrain` 外推填充——看起来像场景的一部分，但流体只存在于世界内（无粒子），`toWorld` 对界外点击返回 null（不能放置）。即"摄像机拍到了边界外"。
2. **遮挡**：原绘制序里气流粒子/轨迹在旗杆、旗面、太阳**之后**画，粒子会从太阳和旗杆表面"爬过"，破坏层次。

## 修法

- **取景**（`controller.fit` + `sf-game` CSS）：画布元素按世界宽高比 contain 贴合（`canvas.style.width/height = 世界尺寸 × min(宿主比)`），`position:absolute; inset:0; margin:auto` 居中；渲染视口从此恒等于世界边界，界外留白是页面底色（画面外框），不再渲染假天空，也不存在点击死角。HUD/状态栏/过关弹层/开发面板均在画布之外，不受影响。
- **遮挡契约**（`render.draw` 绘制序）：云/太阳光晕最背景 → **气流粒子与轨迹** → 旗杆 → 地形 → 太阳 → 旗面/抵达圆 → 源 → 飞机拖尾 → 飞机。粒子从此被旗杆、旗面、太阳、地形遮挡；云保持原样（最背景）；飞机与飞机拖尾是主角层恒在最前。序已写入 AGENTS.md 架构边界。

## 验证（pitfalls H1 数值化探针，headless Chrome）

- 桌面 1280×800：画布 975.8×719，aspect 1.3571 == 世界 76/56，高边贴合、双轴居中误差 0，界外为页面底色（截图确认太阳/旗杆上无粒子）
- 宽受限 500×719（竖屏形态）：画布 500×368.4，aspect 1.3572，双轴居中
- 画布内合成点击：热源 2→1 且 URL 回写 `src=34.2-22.4-h`（放置管线在缩小后的画布上工作正常）

## 遗留

- 界外留白目前是页面奶油底色，与画面边沿有可见接缝——这是"取景框"的本意（边界诚实）。若老大觉得需要更精致的画框（发丝描边/阴影），一句话即可加。

## 修订（老大验收反馈，2026-08-06）

取景方案**回退**：画布缩小居中导致宽屏左右/竖屏底部露出页面底色（白边），游戏画面不能总是填满屏幕。老大澄清 #22 原意是「气流粒子应在左边边缘可见（如右缘一样）」，而非裁剪取景。

- **取景回退**：`controller.fit` 恢复 `renderer.resize(宿主全尺寸)`，`sf-game` 画布恢复 `width/height: 100%`——满屏铺满，界外天空照旧外推填充（宽屏/竖屏均无白边）。
- **左缘气流**：根因是粒子重生范围 `x = 2 + rand*(w-4)` 在左缘留 2 单位真空带，且风向右吹、左缘粒子一出现即被带走。改为满宽重生 `x = 0.6 + rand*(w-1.2)`，左缘恒有新鲜粒子与轨迹，与右缘对称。
- **保留**：遮挡契约（气流粒子/轨迹在旗杆/旗面/太阳/地形之后）不变。
- 验证：headless 探针 1280×719 与 500×719 两形态下 canvas rect == host rect（满屏，无白边）；`bun run check` 全绿。
