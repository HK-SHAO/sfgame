# #23 渲染数值运算迁移 AssemblyScript/WASM

- **状态**：已完成，`bun run check` 全绿；新旧内核逐位一致
- **日期**：2026-08-06

## 评估（先基准后动手，吸取 I1 教训）

渲染侧仅剩的 CPU 数值大头是**顶点批构建**（`MeshBatch`：斜接折线、渐变圆盘、描边几何展开），每帧最坏 ~10 万顶点；桌面 bun 实测 0.7–1.3ms/帧（场景而异）。迁移方式选"方法级粒度"（每个图元方法一次跨边界、内循环全在 wasm）——正是 #20 流体内核取胜的粒度，避开 MoonBit 逐格调用翻车模式。结论：合适，执行。

## 交付

- **`assembly/batch.ts`**：MeshBatch 全数值移植（tri/rect/rectVGrad/stroke/polyline+Fade/disc/discGrad/discGradCore/ring/arc/dashRing）。静态容量 192K 顶点（最坏场景 ~2 倍余量）+ stub runtime 运行期零分配、`memory.buffer` 视图恒定；容量溢出整体丢弃图元（安全饱和，不越界）。polyline 入参经暂存缓冲传递，跨边界只走指针与标量。
- **`src/render/wasm/sfbatch.wasm`**：7.48KB（gzip 3.56KB）。
- **`src/render/batch.ts`**：改为引导 + 薄包装（`initBatchWasm`/`bootBatchWasm` 同 fluid 模式；`data`/`count` 为 wasm 内存视图/直读）。公共 API 不变 → `render.ts`、`gl.ts` 零改动；背景烘焙走同一 batch，一并加速。
- **引导/构建**：`main.ts` 并行加载双内核、任一失败即错误页（绝不静默）；`tests/setup.ts` 双预热；`build:wasm` 编两个产物；`.gitignore` 补 render wasm。
- **测试**：`batch.test.ts` 适配静态容量语义（饱和整体丢弃、reset 复用、polylineFade 逐顶点 alpha），几何行为测试保留。

## 正确性

同场景（400 拖尾粒子 + 云 + 地形 + 旗 + 源 + 弧）新旧实现 **73,671 顶点 / 442,026 float 逐位一致**。对照过程抓出并修复一处 AS 整数字面量相除截断（`7/27`→0，渐变环系数全错）——已回写 pitfalls I9，结论：**AS 移植必须逐位对照，目测不可信**。

## 性能（如实）

桌面 bun（JSC）同场景 1.324 → 1.190ms（**1.11×**），另消除旧 JS 批扩容的 Float32Array 翻倍 GC 负担（稳态零分配）。桌面级 JIT 引擎上倍率不大——这是 I1 预言的 wasm 调用开销地板；弱 JIT/内存受限浏览器余量更大。建议老大 iPhone 实玩试跑（dev 面板有顶点/上传量可参考）；若真机无感，此迁移的价值在架构一致性（数值计算全在 WASM）与零 GC，而非桌面帧率。

## 修订（2026-08-06，随老大要求「物理与渲染同一 wasm」落地）

**合并为单引擎**：物理与渲染数值内核合一——`assembly/engine.ts`（`export * from './main'` + `'./batch'`）单次 asc 编译 → `src/wasm/sfengine.wasm`（16.9KB，gzip 7.0KB），单模块单内存（流体内存与顶点批缓冲同址，~6MB 定型、零分配）。

- **`src/wasm/engine.ts`**：引擎引导/实例化（`initEngine`/`bootEngine`/`createEngine`），`EngineHandle` 持有导出面、内存与共享 `ambient`；每实例独立内存（测试/无头隔离），浏览器每关一个实例（controller 创建，keyed 重建即释放）。
- **门面**：`sim/fluid.ts`、`render/batch.ts` 变为薄门面（公开 API 不变，无头脚本/既有测试零改动）；`LevelSimulation`/`Renderer` 改注入引擎。
- **共享内存收益（渲染零拷贝）**：`drawTracers` 原每粒子每帧 2 次 wasm 跨边界采样（400 粒子 ≈ 800 次调用）改直读 u/v/t 字段视图 + 纯函数 `bilinearSample`（与 wasm 采样逐位同构：clamp [0, n-1.001]、双线性、速度叠 ambient；新增逐位对照测试守护）。旗布/风探针等游戏性采样保持导出调用，位级不变。
- 引导链单点化：main.ts 单 fetch、setup.ts 单预热、run-level 单加载；旧 `src/sim/wasm/`、`src/render/wasm/` 已删。
- 物理逐位不变由「同一内核代码重导出 + solutions.test.ts ±2s」守护；`bun run check` 全绿（53 项测试）。
- 性能：桌面帧率几乎不变（wasm 调用本身廉价），收益在弱 JIT 移动端的跨边界消除与单实例内存；请在 iPhone 实玩对照 dev 面板数字。
