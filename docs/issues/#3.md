- **日期**：2026-08-04

## 方案要点

1. **玩法视角不变**：竖屏仍按 contain 全场景可见（益智游戏必须一眼看全地图：飞机、目标、可放置区），不做裁剪或镜头跟随。
2. **消灭"死"留白**：原来竖屏上下两条页面底色 letterbox 改为**延伸的场景**——天空渐变向上延伸、大地向下填充（canvas 渐变端色钳制 + 地形多边形延伸出世界边界），画面成为连续场景而非贴块。横屏/超宽屏的左右留白同样被天空与大地填满。
3. **HUD 竖屏窄屏压缩**（≤520px）：隐藏关卡名 chip（信息选关页已有），返回/计数/重置/声音按钮两端对齐；引导文案字号微缩。安全区 env() 适配原有保留。
4. **移除「横屏体验更佳」提示**：竖屏已是正式适配的一等体验，不再劝转屏。

## 顺带修复

- 纸飞机从画布外飞入（见 #5）时，旧渲染会把世界外画成页面底色；现延伸天空承接入场轨迹，视觉连贯。
