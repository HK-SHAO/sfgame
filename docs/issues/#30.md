# #30 反馈音效、震动与程序化背景音乐

状态：已执行完毕（2026-08-08），待老大验收。

## 资料学习摘要（先于动手）

- **jsfxr/sfxr 参数体系**：一次性音效 = 波形 + ADSR 包络（attack/sustain/punch/decay）+ 频率滑移 ramp + 滤波。对照发现本项目既有实现已暗合其经典 preset 模式：place = 快攻 sine + 频率下滑（jump/laser 的 ramp 思想），land = 噪声脉冲 + 低通（hitHurt 模式），win = 上行琶音（arp），reward = 双音 chime。本次沿用该体系，新增音效保持同一语言（快攻 12ms 防爆音、指数衰减、±5% 随机失谐防机械感）。
- **WebAudio 调度**（"A Tale of Two Clocks" 模式）：音乐音符绝不靠 setTimeout 直接触发，而是小步 lookahead 调度到 `ctx.currentTime` 时间轴——后台 `ctx.suspend` 时音频时钟冻结，调度自然暂停，恢复无缝续播，零积压。
- **生成式环境音乐原则**（Eno 式）：慢（≤62 BPM）、稀疏、大调五声音阶（任意组合无半音冲突，随机生成恒和谐）、长音交叠 legato、纯 sine 音色（无泛音 = 无嘈杂感的物理保证）。

## 架构（一致性 / 解耦 / 内存）

- **`app/core/feedback.ts`（新）**：语义反馈门面 `fb`——一个操作事件 = 音效 + 震动的**唯一配对点**，UI/controller 离散反馈一律走 `fb`；音频图（sfx）与震动（haptics）各自独立。静音开关同时管辖声音与震动（单一"安静模式"语义）。
- **`app/core/haptics.ts`（新）**：Vibration API 封装，无状态零内存。iOS Safari 不支持该 API → 特性检测后静默 no-op（仅 Android 系生效）。
- **`app/core/music.ts`（新）**：`bakeScore(seed)` 纯函数烘焙**可 JSON 序列化乐谱**（确定性 PRNG，可无头测试）；`MusicPlayer` lookahead 调度播放，由 `sfx` 在解锁时以共享 ctx/master 实例化（静音/后台挂起对音乐自动生效）。
- 连续风声层与音乐传输（start/stop/duck）是音频引擎内部状态，仍由 controller 直驱 `sfx`——规则已记入 AGENTS.md。

## 反馈清单（事件 → 音效 + 震动）

| 事件 | 音效 | 震动 |
|---|---|---|
| 放热/冷源 | 既有下滑 bloop | 12ms 轻点 |
| 抓起道具（新增） | 45ms 极轻 tick | 8ms |
| 移除道具 | 既有 | 10ms |
| 放置被拒 | 既有低哑方波 | 双段 24-48-24ms |
| 落地 | 既有噪声 thump（响度∝冲击） | ∝冲击 6-36ms |
| 抵达旗子 | 既有 reward 双音 | 双点 |
| 过关 | 既有琶音 | 渐强三段 |
| 暂停/恢复（新增） | 下行/上行 soft blip 一对 | 8ms |
| UI 导航/选项卡组切换（新增补漏） | click/enter/back/reset | **不震**（高频震动即噪音） |

落地门槛（impact < 0.6 不反馈）从 sfx 上移至 fb 单点把关。dev 页面内部操作不配音效（非玩家面）。

## 背景音乐设计

- **统一系统 + 按关卡微调**：`sfx.musicForLevel(level.id)` 以关卡 id 为种子烘焙——同一套五声音阶环境音乐，各关仅在 root（G3/A3/C4/D4）、bpm（54-62）、和弦走向（4 种预设）、旋律游走上微调。修了一个真 bug：相邻小种子的 mulberry32 输出流头部强相关，各关 root 全撞 C4——先对种子做位混合打散。
- **乐谱结构**（8 小节循环，约 30 音符）：每小节 pad 长音 2-3 个（根+五度+偶发高八度，慢起 0.8s 慢落，尾音跨小节交叠）；pluck 稀疏旋律（密度 ~1/4 拍点，音阶内随机游走并限域）。
- **音色**：全部纯 sine（简单、和谐的物理保证）；pluck 经一条共享反馈延迟链（0.34s、低通反馈防高频堆积）获得空间感——不用 convolver reverb（脉冲响应 buffer 占内存）。音乐总线增益 0.22，压在风声层之下；过关时 duck 至 0.1 让位给胜利琶音；换关留 700ms 静默间隔防调性叠混。
- **内存**：乐谱 ~30 个数值对象；调度器只提前 0.35s 排程，并发节点 ≤十余个，每个音符 ended 即断开整链（沿用 F3 坑的防护）；start/stop 竞态用代际计数器防护，迟到的启动定时器不得复活已停乐谱。
