## 设计：声音是物理量的函数，不是预录音效

全部 WebAudio 实时合成，零依赖、零素材：

1. **声源 = 粉红噪声**：Paul Kellet IIR 滤波算法把白噪声逼近 1/f 功率谱——自然风湍流的能量分布特征，听感远真于白噪声。
2. **风场底噪**：噪声 → 带通 → 增益。响度 ∝ (v/vFull)²（气动噪声随流速非线性增长的近似），带通中心频率随风速上移（快风更"亮"）。v 取全场探针 + 飞机位置的风速均值。
3. **飞机气动摩擦声（核心）**：由**飞机相对空气的速度** |v_plane − v_air| 驱动——这正是空气摩擦的物理定义：随风同飘时相对速度≈0、近乎无声；逆风、坠落、被风冲击切割空气时呼啸渐强。声音本身在教物理。
4. **落地撞击声**：噪声脉冲，响度与低通截止频率随撞击速度增大（动能→声能）。
5. 指数平滑（时间常数 0.18~0.6s）避免音量抖动；iOS 手势解锁、页面隐藏挂起、静音经主增益统一生效（覆盖连续声层）。
