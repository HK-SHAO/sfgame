# #8 第二关「降落」—— 下沉风

## 我要表达什么

第 1 关教了"热主升"，第 2 关补全对偶的另一半：**冷主降**。一升一降，风的方向由温度差决定——两关合起来才是完整的热对流叙事。关卡因此刻意极简：一道缓缓加深的山谷，没有障碍、没有新机制，全部张力来自"落点的取舍"。

## 设计

- **布局**：76×56 谷地（左浅右深），目标在右侧更深处。飞机自左外侧高空（y=8）入场，随 2.6 的谷风右行。
- **不操作的失败是教学本身**：飞机会从目标圈上方约 8 个单位处掠过、撞上远处谷壁——玩家亲眼看到"太高了"，冷源的意义不言自明。
- **谜题**：在航线下方布置冷源，下沉风把飞机压进谷底。放早了摔在目标之前，放晚了掠过头顶。
- **预算**：热 2 / 冷 3（冷为主角，热留给试错与对照实验）。

**选型说明（批判性取舍）**：最初按"翻山"概念实现——迎风坡热柱托升越脊、背风坡冷源压落。无头实测发现轻质量飞机在强热柱中轨迹混沌：直冲画布顶、被顶部外流吹回、摆放差 1–2 单位结果剧变（通关需 84s 的混乱漂流）。这与"不杂乱、较简洁"相悖，遂整体放弃，改选降落概念——冷下沉路径平滑、容错宽、叙事干净。沉没成本不留。
